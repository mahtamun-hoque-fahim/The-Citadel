# The Citadel

Packaged Claude skills for Fahim's indie dev pipeline. Each `.zip` is one self-contained skill (validated via `skill-creator`'s `quick_validate.py` before packaging).

Pushed by Claude on request. Say "update skills" in a Claude session to refresh this repo with the latest versions from `/mnt/skills/user/`.
